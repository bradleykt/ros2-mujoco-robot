# ROS 2 + MuJoCo Robotics Project

A robotics software project using ROS 2 and MuJoCo.

## Goals

- Build a simulated robotic system
- Develop ROS 2 Python nodes
- Implement robot control
- Add diagnostics and monitoring
- Develop automated testing and evaluation

## Technologies

- ROS 2 Jazzy
- Python
- MuJoCo
- Git / GitHub
